Chat widget preview harness

Serves src/engine.js and dealers/*.json straight off disk with Cache-Control: no-store. Edit a dealer config or the engine, hit refresh, see it. No build, no tag, no CDN, no purge.

This runs the same code path as a built bundle: the engine applies window.CW_CFG last, so the config here lands exactly where the baked-in dealer config would. CloseBot is mocked here — its real script refuses to mount on an unrecognised domain (/widget-for-page returns 204). The mock reproduces its DOM and its own theme CSS, including the inline --cb-color, so anything our CSS must beat is present.
